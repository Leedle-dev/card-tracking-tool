Population Data Sources Research Note

Last checked: 2026-05-28

Purpose

This note tracks where population and grade-rate data can come from, how reliable each source looks, and what was found for the Houndoom grading model test case.

Target Houndoom Cards

- English: Shrouded Fable, SFA, 066/064, Illustration Rare
- Japanese: Night Wanderer, SV6a, 066/064, Art Rare
- Simplified Chinese: Gem Pack Vol. 5, CBB5C, 0807/07, Triple Rare

Source Strategy

1. GemRate
   - Best conceptual source for model inputs.
   - Public pages expose useful PSA set and card-level data through indexed pages.
   - Partner API exists for unified PSA, Beckett/BGS, SGC, and CGC population data, but it appears to be commercial / partner access rather than a free public API.
   - Useful for grade-rate and trend context when public pages are indexed.
   - Important Beckett convention: GemRate / BGS gem rate should be treated as BGS 9.5 or higher.
   - Treat GemRate as the preferred analytical source if access becomes affordable or if public pages are enough for a card.

2. PriceCharting
   - Useful fallback for PSA and CGC population tables.
   - Exposes per-grade PSA and CGC population counts in static page text.
   - Updates monthly.
   - Half-grade populations are folded into the nearest whole grade, so it is not suitable for clean CGC 9.5 or BGS 9.5 modeling.
   - Also exposes rough graded price estimates, including BGS 10 Black and CGC Pristine 10, but those are prices rather than population counts.

3. PSA official population report
   - Official source for PSA population data.
   - Direct scripted requests currently hit Cloudflare challenge pages.
   - Browser/manual lookup may still work.
   - Use official PSA pages for manual verification when necessary, but do not assume automated collection is reliable.

4. Beckett / BGS official population report
   - Official source for BGS population data.
   - Public pages are discoverable, but static HTML did not expose useful card-grade rows during this test.
   - Some pages appear to require login or subscription context for search results.
   - This is a key source because BGS 9.5, Pristine 10, and Black Label 10 should be modeled separately.
   - Near-term approach: manual lookup and entry, unless a stable public endpoint is found.

5. CGC official population report
   - Official source for CGC population data.
   - Public pages are Angular/dynamic and static fetches show template placeholders rather than loaded rows.
   - Search results can expose set pages, but automated extraction needs more investigation.
   - PriceCharting is easier for broad PSA/CGC grade buckets, but official CGC will be needed for Pristine 10 vs Gem Mint 10 separation.

Initial Findings

- GemRate is the best single source if API access is available.
- PriceCharting is the easiest static fallback for PSA and CGC whole-grade population snapshots.
- Official PSA, BGS, and CGC sites should be treated as manual verification sources unless a stable accessible endpoint is found.
- BGS remains the biggest data gap for the Beckett thesis because public fallback sources mostly provide prices, not clean BGS population by 9.5 / 10 / Black Label.
- CGC 10 data is available through PriceCharting, but CGC Pristine 10 vs Gem Mint 10 requires official CGC or GemRate-style detail.

Model Implications

- Store source and confidence on every population snapshot.
- Do not mix PriceCharting CGC 10 with CGC Pristine 10; PriceCharting's population table only shows whole-grade CGC buckets.
- Do not treat GemRate and PriceCharting totals as contradictory without checking update dates and taxonomy.
- For cards with sparse Chinese data, use Japanese grade-rate priors and mark the assumption explicitly.
